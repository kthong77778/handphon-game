# 🍢 분식집 키우기 — 방치형 모바일 게임

탭해서 조리하고, 설비를 늘리고, 자리를 비운 동안에도 돈이 쌓이는 **방치형(Idle) 웹게임**입니다.
설치 없이 휴대폰 브라우저에서 바로 돌아가고, 홈 화면에 추가하면 앱처럼 실행됩니다.

## 플레이

- **🏪 가게** — 가운데를 탭하면 즉시 수익. 아래에서 설비/직원을 사면 초당 수익이 붙습니다.
  `×1 / ×10 / 최대` 버튼으로 한 번에 여러 개 구매할 수 있습니다.
- **🔥 콤보** — 1.2초 안에 계속 탭하면 콤보가 쌓입니다. 콤보 1당 탭 수익 +4%,
  50콤보에서 최대 ×3. 손을 떼면 풀립니다.
- **📣 손님 몰이** — 60초 동안 모든 수익 ×3. 쿨다운 15분(명성 상점으로 단축).
- **🌟 황금 손님** — 1~2분에 한 번 화면 어딘가에 나타납니다. 9초 안에 탭하면
  현금 다발(초당 수익 4분치) · 손님 폭주(30초 수익 ×7) · 신들린 손(30초 탭 ×25) 중 하나.
- **📅 출석 보상** — 하루 한 번. 연속 출석하면 커져서 7일차엔 초당 수익 3시간 30분치를 줍니다.
- **🚨 도둑 & 경찰** — 3~7분에 한 번 도둑 🦹 이 💸 을 들고 화면을 가로지릅니다.
  7.5초 안에 탭해서 직접 잡으면 **피해 0 + 보너스**, 뒤따라온 경찰차 🚓 가 잡으면 **피해 0**,
  놓치면 그때 돈이 빠집니다(보유액의 8%와 초당 수익 3분치 중 작은 쪽).
  설비·업그레이드·명성은 절대 건드리지 않고, 훔칠 돈이 없으면 아예 나타나지 않습니다.
  명성 상점의 `🚓 야간 순찰`로 경찰의 자동 검거 확률을 15% → 85%까지 올릴 수 있습니다.
- **🚶 가게 앞 거리** — 손님들이 오갑니다. 초당 수익이 오를수록 붐비고,
  손님 몰이 중엔 다들 뛰어옵니다. 셋 중 하나는 가게 앞에 멈춰 주문하고 갑니다.
- **🍱 성장하는 메뉴** — 탭 수익이 오르면 조리하는 음식이 8단계에 걸쳐 고급스러워집니다.
  어묵 꼬치에서 시작해 프리미엄 한상까지, 단계마다 테두리도 화려해집니다.
- **👑 손님 등급** — 초당 수익이 오르면 거리에 오는 손님의 격이 5등급까지 올라갑니다.
  `동네 손님 → 소문 난 가게 → 차려입은 손님 → VIP 손님 → 재벌 손님`.
  3등급부터는 정장 차림에 🎩 모자·👜 가방을 들고 오고, VIP는 💼 서류가방과 🥂 샴페인,
  재벌은 👑 왕관·💎 보석·🏆 트로피를 들고 옵니다. 등급이 오르면 은은한 빛도 함께 짙어지고,
  거리 자체도 보도 → 자주색 → **레드카펫(금색 테두리)** 로 바뀝니다.
- **🎨 스킨** — 설정 탭에서 취향대로 고릅니다. 고른 스킨 안에서 성장은 그대로 이어집니다.
  - 조리 음식 5종: 분식 성장형 · 붕어빵 가게 · **주먹밥 부락**(얼굴 달린 캐릭터) · 떡·디저트 · 면 요리
  - 가게 앞 손님 4종: 동네 → 재벌 · 동물 친구들 · 판타지 · 탈것 거리
- **⬆️ 업그레이드** — 조건을 만족하면 열립니다. 한 번 사면 해당 회차 내내 적용.
- **✨ 환생(재개업)** — 가게를 정리하고 **명성**을 얻습니다. 명성 1당 모든 수익 +2%,
  명성 상점에서 영구 강화 8종(수익 배율, 탭 강화, 오프라인 시간/효율, 시작 자금,
  설비 할인, 황금 손님 빈도, 손님 몰이 쿨다운)을 살 수 있습니다.
- **🏆 도전과제** — 28종. 하나 달성할 때마다 모든 수익 +1% 영구 증가.
- **🏅 명예의 전당** — 기록 탭에 개인 최고 기록 8종(한 회차 최고 매출, 최고 순간 초당 수익,
  한 번에 가장 많이 번 탭, 최고 명성, 최단 환생 시간 등)과 **역대 회차 순위표**가 있습니다.
  환생할 때마다 그 회차가 매출·명성·소요 시간과 함께 기록되고, 명성 순으로 줄을 섭니다
  (동점이면 빨리 끝낸 회차가 위). `지금 재개업하면 N위` 표시가 실시간으로 붙어,
  더 버틸지 지금 끊을지 판단할 수 있습니다. 기록은 환생해도 남고 최근 50회차까지 보관합니다.
- **😴 오프라인 수익** — 게임을 꺼둔 동안에도 돈이 쌓입니다.
  기본 4시간 · 50% 효율에서 시작해 명성 상점으로 최대 28시간 · 150%까지 늘어납니다.

세이브는 브라우저 `localStorage`에 10초마다 자동 저장되고, 설정 탭에서 코드로 백업/복원할 수 있습니다.

## 매크로(오토클릭) 방지

사람을 잘못 막는 쪽이 봇을 놓치는 쪽보다 나쁘다고 보고, 서로 독립적인 신호가
**동시에** 맞을 때만 막습니다. 벌은 몇 초 쉬는 것으로 끝나고, 세이브에 손대지 않습니다.

1. **`isTrusted` 검사** — 콘솔이나 확장 프로그램이 만들어낸 가짜 클릭은 인정하지 않습니다.
   오탐이 없는 정확한 판정이라, 웹에서 흔한 매크로는 여기서 대부분 걸러집니다.
   황금 손님도 같은 검사를 거칩니다.
2. **초당 상한 14회** — 하드웨어 오토클릭이라도 사람보다 더 벌 수는 없습니다. 초과분만 무효.
3. **간격 + 좌표** — 최근 32번의 탭 간격이 기계처럼 고르고(변동계수 0.09 미만)
   *동시에* 좌표가 2px 안에서만 움직일 때 5초간 조리가 멈춥니다.
   간격만 보면 리듬 타듯 치는 사람이 걸리고, 좌표만 보면 마우스를 안 움직이는
   사람이 걸립니다. 둘 다여야 봇입니다.

`assets/js/game.js` 의 `MACRO` 값으로 조절할 수 있습니다.
연타 습관 8종 × 400회 시뮬레이션에서 사람 오탐 0%, 오토클릭 6종 탐지 100%입니다.
다만 **메트로놈처럼 정확하면서 손을 1px도 안 움직이는 연타는 봇과 구분되지 않습니다** —
이 경우 5초 쉬었다 이어집니다.

## 실행 방법

가장 간단한 방법은 `index.html`을 브라우저로 여는 것입니다.
다만 서비스워커(오프라인 실행)는 `http(s)`에서만 동작하므로, 개발 중에는 로컬 서버를 권장합니다.

```bash
# Python 이 있으면
python -m http.server 8000

# Node 가 있으면
npx serve .
```

브라우저에서 `http://localhost:8000` 접속. 휴대폰으로 테스트하려면 PC와 같은 와이파이에 연결한 뒤
`http://<PC의 내부IP>:8000` 으로 접속하면 됩니다.

## 배포 (GitHub Pages)

이 저장소는 빌드 과정이 없는 정적 사이트라 그대로 올리면 됩니다.

1. GitHub 저장소 → **Settings → Pages**
2. Source: `Deploy from a branch`, Branch: `main` / `/(root)` 선택 후 저장
3. 1~2분 뒤 `https://kthong77778.github.io/handphon-game/` 에서 접속

## 프로젝트 구조

```
index.html               화면 구조 (탭 5개)
manifest.webmanifest     PWA 설정 (홈 화면 추가용)
sw.js                    서비스워커 (오프라인 실행 캐시)
assets/
  css/style.css          모바일 우선 다크 테마, 노치/홈바 안전영역 대응
  js/
    format.js            숫자 표기 (만·억·조·경·해 …)
    data.js              밸런스 데이터 — 설비 10종, 업그레이드 65종, 명성상점 6종, 도전과제 20종
    state.js             세이브 저장·불러오기·검증 (깨진 데이터 방어)
    game.js              수익 계산, 구매, 환생, 오프라인 보상
    ui.js                DOM 렌더링, 입력 처리
    main.js              부팅, 게임 루프, 자동 저장
  icon.svg               앱 아이콘
```

밸런스를 바꾸려면 `assets/js/data.js` 의 숫자만 고치면 됩니다.
설비 가격은 1개 살 때마다 1.15배씩 오르고, 환생 시 얻는 명성은 `(이번 회차 매출 / 100만) ^ 0.4` 입니다.
황금 손님 · 손님 몰이 · 출석 보상 수치도 같은 파일의 `GOLDEN` / `BOOST` / `DAILY` 에 모여 있습니다.

`주먹밥 부락` 스킨은 이모지가 아니라 직접 그린 인라인 SVG 캐릭터입니다
(`data.js` 의 `onigiri()`). 단계마다 재료가 얹히고 표정이 바뀝니다. 단계에 `svg` 가 있으면
큰 화면과 단계표에서는 그림을, 말풍선처럼 작은 곳에서는 `icon`(이모지)을 씁니다.

스킨을 늘리려면 `TAP_SKINS` / `CROWD_SKINS` 에 항목을 추가하면 됩니다.
단계가 오르는 문턱은 모든 스킨이 `TAP_STEP_AT` · `CROWD_TIER_AT` 을 공유하므로
새 스킨은 아이콘과 이름만 8개(음식) 또는 등급별 후보(손님)만 채우면 됩니다.
문턱은 자동 플레이 시뮬레이션으로 잡았습니다 — 첫 회차 하루 안에 음식 6단계까지 보이고,
7·8단계와 손님 4·5등급은 환생 이후의 목표가 됩니다 (환생 반복 시 약 2.8일에 전부 도달).

수익 계산은 업그레이드 65종을 전부 훑어야 해서, `game.js` 안에서 값이 바뀔 때만 다시 계산하도록
캐시해 둡니다. 세이브를 직접 건드리는 코드를 추가한다면 반드시 `Game.invalidate()` 를 함께 부르세요.

## 진행 속도

자동 구매 시뮬레이션 기준입니다. 처음 2분만 손으로 조리해 종잣돈을 만들고,
그 뒤로는 가성비가 가장 좋은 설비/업그레이드를 자동으로 사도록 돌렸습니다.
황금 손님과 손님 몰이는 제외한 수치라 실제로는 이보다 빠릅니다.

| 경과 | 누적 매출 | 초당 수익 | 환생 시 명성 |
|---|---|---|---|
| 5분 | 2,722원 | 9원 | 0 |
| 1시간 | 49.6만원 | 488원 | 0 |
| 3시간 | 2757만원 | 9,186원 | 3 |
| 6시간 | 3.24억원 | 5.06만원 | 10 |
| 12시간 | 39.5억원 | 33.7만원 | 27 |
| 24시간 | 333억원 | 111만원 | 64 |

첫 환생은 대략 1시간 15분 전후에 가능합니다.
