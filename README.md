# 🍢 분식집 키우기 — 방치형 모바일 게임

탭해서 조리하고, 설비를 늘리고, 자리를 비운 동안에도 돈이 쌓이는 **방치형(Idle) 웹게임**입니다.
설치 없이 휴대폰 브라우저에서 바로 돌아가고, 홈 화면에 추가하면 앱처럼 실행됩니다.

## 플레이

- **🏪 가게** — 가운데를 탭하면 즉시 수익. 아래에서 설비/직원을 사면 초당 수익이 붙습니다.
  `×1 / ×10 / 최대` 버튼으로 한 번에 여러 개 구매할 수 있습니다.
- **🔥 콤보** — 1.2초 안에 계속 탭하면 콤보가 쌓입니다. 콤보 1당 탭 수익 +4%,
  50콤보에서 최대 ×3. 손을 떼면 풀립니다.
- **📣 손님 몰이** — 60초 동안 모든 수익 ×3. 쿨다운 15분(명성 상점으로 단축).
- **🌟 황금 손님** — 1~2분에 한 번 화면 어딘가에 나타납니다. 9초 안에 탭하면
  현금 다발(초당 수익 4분치) · 손님 폭주(30초 수익 ×7) · 신들린 손(30초 탭 ×25) 중 하나.
- **📅 출석 보상** — 하루 한 번. 연속 출석하면 커져서 7일차엔 초당 수익 3시간 30분치를 줍니다.
- **⬆️ 업그레이드** — 조건을 만족하면 열립니다. 한 번 사면 해당 회차 내내 적용.
- **✨ 환생(재개업)** — 가게를 정리하고 **명성**을 얻습니다. 명성 1당 모든 수익 +2%,
  명성 상점에서 영구 강화 8종(수익 배율, 탭 강화, 오프라인 시간/효율, 시작 자금,
  설비 할인, 황금 손님 빈도, 손님 몰이 쿨다운)을 살 수 있습니다.
- **🏆 도전과제** — 25종. 하나 달성할 때마다 모든 수익 +1% 영구 증가.
- **😴 오프라인 수익** — 게임을 꺼둔 동안에도 돈이 쌓입니다.
  기본 4시간 · 50% 효율에서 시작해 명성 상점으로 최대 28시간 · 150%까지 늘어납니다.

세이브는 브라우저 `localStorage`에 10초마다 자동 저장되고, 설정 탭에서 코드로 백업/복원할 수 있습니다.

## 실행 방법

가장 간단한 방법은 `index.html`을 브라우저로 여는 것입니다.
다만 서비스워커(오프라인 실행)는 `http(s)`에서만 동작하므로, 개발 중에는 로컬 서버를 권장합니다.

```bash
# Python 이 있으면
python -m http.server 8000

# Node 가 있으면
npx serve .
```

브라우저에서 `http://localhost:8000` 접속. 휴대폰으로 테스트하려면 PC와 같은 와이파이에 연결한 뒤
`http://<PC의 내부IP>:8000` 으로 접속하면 됩니다.

## 배포 (GitHub Pages)

이 저장소는 빌드 과정이 없는 정적 사이트라 그대로 올리면 됩니다.

1. GitHub 저장소 → **Settings → Pages**
2. Source: `Deploy from a branch`, Branch: `main` / `/(root)` 선택 후 저장
3. 1~2분 뒤 `https://kthong77778.github.io/handphon-game/` 에서 접속

## 프로젝트 구조

```
index.html               화면 구조 (탭 5개)
manifest.webmanifest     PWA 설정 (홈 화면 추가용)
sw.js                    서비스워커 (오프라인 실행 캐시)
assets/
  css/style.css          모바일 우선 다크 테마, 노치/홈바 안전영역 대응
  js/
    format.js            숫자 표기 (만·억·조·경·해 …)
    data.js              밸런스 데이터 — 설비 10종, 업그레이드 65종, 명성상점 6종, 도전과제 20종
    state.js             세이브 저장·불러오기·검증 (깨진 데이터 방어)
    game.js              수익 계산, 구매, 환생, 오프라인 보상
    ui.js                DOM 렌더링, 입력 처리
    main.js              부팅, 게임 루프, 자동 저장
  icon.svg               앱 아이콘
```

밸런스를 바꾸려면 `assets/js/data.js` 의 숫자만 고치면 됩니다.
설비 가격은 1개 살 때마다 1.15배씩 오르고, 환생 시 얻는 명성은 `(이번 회차 매출 / 100만) ^ 0.4` 입니다.
황금 손님 · 손님 몰이 · 출석 보상 수치도 같은 파일의 `GOLDEN` / `BOOST` / `DAILY` 에 모여 있습니다.

수익 계산은 업그레이드 65종을 전부 훑어야 해서, `game.js` 안에서 값이 바뀔 때만 다시 계산하도록
캐시해 둡니다. 세이브를 직접 건드리는 코드를 추가한다면 반드시 `Game.invalidate()` 를 함께 부르세요.

## 진행 속도

자동 구매 시뮬레이션 기준입니다. 처음 2분만 손으로 조리해 종잣돈을 만들고,
그 뒤로는 가성비가 가장 좋은 설비/업그레이드를 자동으로 사도록 돌렸습니다.
황금 손님과 손님 몰이는 제외한 수치라 실제로는 이보다 빠릅니다.
