## 1. 앱으로 감싸기 — Capacitor 추천

정적 웹을 앱으로 만드는 길은 둘. **오프라인 + 로컬 알림 + (나중에) 광고**를 계획하므로 Capacitor 를 권한다.

| | Capacitor (추천) | TWA (Bubblewrap) |
|---|---|---|
| 방식 | 웹을 앱 안에 **번들**(오프라인 확실) | 설치된 크롬으로 **웹을 띄움** |
| 로컬 알림·광고·IAP | **쉽다**(플러그인) | 웹푸시 필요·제약 많음 |
| 우리 `BunsikNative` 브릿지 | **여기에 딱 맞음** | 안 맞음 |
| 난이도 | 조금 더 있음 | 아주 쉬움 |

**Capacitor 최소 절차**
- [ ] Node 설치된 상태에서 프로젝트에 Capacitor 추가
  `npm i @capacitor/core @capacitor/cli && npx cap init`
- [ ] 웹 자산 폴더를 `webDir` 로 지정(이 저장소 루트를 그대로)
- [ ] 안드로이드 추가: `npm i @capacitor/android && npx cap add android`
- [ ] 로컬 알림 플러그인: `npm i @capacitor/local-notifications`
      → `window.BunsikNative.scheduleNudges` 를 이 플러그인으로 구현 (docs/알림설계.md 참고)
- [ ] `npx cap sync` 후 `npx cap open android` 로 Android Studio 열기

## 5. 아이콘 다시 만들기 (지금 별점을 깎는 1순위)
현재 아이콘은 **이모지 + 그라데이션** = 플레이스홀더처럼 보인다. 인게임 손그림(shop.png)은
상용 수준이니, **같은 화풍의 커스텀 아이콘**을 만든다.
- [ ] 주제 **하나만** (예: 김 나는 떡볶이 한 그릇 / 포장마차 정면 클로즈업)
- [ ] 프레임 **꽉 차게** — 얇은 테·검은 여백 금지
- [ ] **48px 로 줄여도 읽히게** 굵고 단순하게, 높은 대비
- [ ] shop.png 만든 **같은 이미지 생성 파이프라인**으로 뽑기
- [ ] 512×512 PNG + 마스커블 안전영역(가장자리 여백 안에 주제) 확인
