### 2.4 확인했으나 문제 없음

- `normalize()` 는 어떤 JSON 이든 throw 하지 않고 `importText`/`load` 도 try 로 감쌈 → 부팅 크래시 경로 없음.
- `lastSeen` 미래값: `elapsed<0` → 보상 0, 다음 자동저장에서 자가 치유.
- `maxAffordable` 부동소수 초과 구매: 1,761회 시도 0건. `earn()`/`cap()`: `MAX_VALUE` 에 닿아도 NaN 없음.

### 2.5 근본 원인 하나

1·2·13 의 뿌리는 **`State.save()` 가 `lastSeen` 을 부수효과로 덮어쓴다**(`state.js:383`)는 점이다. "정산 확정"과 "저장"이 한 함수에 묶여 있어, 정산 전에 누가 저장하든 보상이 사라진다. 수정 방향: `lastSeen` 갱신을 `settleReturn()` 완료 시점(모달 '받기')으로 옮기고, `save()` 는 순수 직렬화만 하게 한다. v2 에서는 이것이 "tick 확정 → 저장" 트랜잭션 분리로 자연히 해결된다.
