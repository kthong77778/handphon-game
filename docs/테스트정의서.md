# 분식집 키우기 — 테스트 정의서

> 실 사용자 관점에서 게임의 모든 기능·상황을 점검한 결과를 정의한다.
> 자동 테스트 스위트(로직·매크로·진행도·브라우저)와, 실제 브라우저를 띄워
> 한 명의 플레이어처럼 화면을 조작하며 확인한 시나리오를 함께 담는다.
> 검증일 기준 코드는 `main` 최신본(PNG 그림 개편본)이다.

- 검증 환경: Chromium(Playwright), iPhone 14 크기(390×844, 모바일·터치)
- 검증 방식: ① 내장 테스트 스위트 실행 ② 실제 페이지를 띄워 탭·버튼 직접 조작 ③ 화면 스크린샷 육안 확인
- 판정: ✅ 통과 · ⚠️ 주의(설계상 정상이나 오해 소지) · ❌ 결함

---

## 1. 테스트 계층

| 계층 | 파일 / 방식 | 무엇을 보는가 | 결과 |
|---|---|---|---|
| 게임 로직 | `node tests/logic.js` | 수익·버프·콤보·환생·퀘스트·랭킹·세이브 등 427개 단정 | ✅ 전부 통과 |
| 매크로 방지 | `node tests/macro-stress.js` | 사람 오탐률 0% / 오토클릭 차단률 100% | ✅ 합격 |
| 진행 속도 | `node tests/progression.js` | 8단계·손님 5등급까지 도달하는 시간 | ✅ 정상 도달 |
| 브라우저 | `node tests/browser.js` | 실제 DOM·연출·조작 | ⚠️ 스위트가 옛 SVG 기준이라 최신 PNG 개편본과 어긋남(§5) |
| 실사용 시나리오 | 본 문서 §3~§4 | 플레이어가 실제로 겪는 흐름 | ✅ 전부 정상(§4) |

> 브라우저 스위트는 그림이 **인라인 SVG**이던 시절 기준으로 `#tapEmoji svg`,
> `.shopfront svg` 등을 찾는다. 현재는 `assets/img/**` 의 **PNG**(`<img>`)로 그려지므로
> 셀렉터가 어긋나 실패로 뜬다. 게임 자체의 결함이 아니라 **테스트가 낡은 것**이다(§5).

## 2. 검증 방법(재현)

```bash
# 의존성 없는 테스트
node tests/logic.js
node tests/macro-stress.js
node tests/progression.js

# 브라우저 테스트 (크로미움 경로를 직접 줄 때)
npm i -D playwright
CHROMIUM_PATH=/경로/chrome node tests/browser.js
node tests/browser.js 도둑        # 이름으로 스위트 하나만
```

실사용 시나리오(§3~§4)는 정적 서버를 띄우고 Playwright로 실제 탭·버튼을 눌러 확인한다.
모달(안내·출석·오프라인·확인 대화상자)이 화면을 덮으므로, 조작 전 **모달을 먼저 닫아야** 한다.

가로 스크롤도 생기지 않았다.

## 5. 발견 사항

### 5.1 결함 — 업그레이드 잠금 문구 "원" 중복 (수정함)

- 현상: 누적 매출로 잠긴 업그레이드(예: **위생 등급 A**)의 조건이
  `이번 판 누적 3.33만 원원 필요` 처럼 **"원"이 두 번** 나왔다.
- 원인: `Fmt.won()` 이 이미 `"… 원"` 을 붙여 돌려주는데,
  `ui.js` 의 `gateReason()` 이 그 뒤에 `'원 필요'` 를 또 붙였다.
- 조치: `Fmt.won(u.needEarned) + '원 필요'` → `Fmt.won(u.needEarned) + ' 필요'` 로 수정.
  같은 패턴은 코드 전체에서 이 한 곳뿐이었다.

### 5.2 브라우저 테스트 실패 20건 전수 분석 — 기능 결함 0건

> 아이콘·그림은 어차피 툴로 재개편할 예정이라, **기능(로직·동작) 결함만** 가려냈다.
> `tests/browser.js` 실패 20건을 하나씩 추적한 결과, **게임 기능 결함은 없었다.**
> 원인은 세 갈래이며, 타임아웃 뒤에 가려져 있던 기능은 전부 따로 직접 조작해 정상임을 확인했다.

**원인 ① 이미지 셀렉터 (그림 개편) — 무시 대상**
스위트가 **인라인 SVG** 시절 기준이라 PNG(`<img>`)로 바뀐 그림을
`#tapEmoji svg`·`.shopfront svg`·`★` 문자 등으로 찾다가 실패한다.
해당: `조리 이모지 변경`, `1단계/최고단계 SVG`, `단계표 8칸 그림`, `스킨 카드 그림`,
`가게 그림이 그려짐`, `조리 이미지가 SVG` 등.

**원인 ② 1회성 안내 모달이 클릭을 가로막음 — 스테일 테스트**
돈·명성을 프로그램으로 올리면 아래 **한 번만 뜨는** 안내가 나타나 이후 클릭을 막는다.
테스트가 이를 닫지 않아 `page.click Timeout` 으로 스위트가 중단된다.
가드 플래그로 실사용에선 딱 한 번만 뜨므로 정상이다.
  - `재개업(환생)이 열렸어요!` — `sawPrestigeIntro` (main.js)
  - `첫 재개업 축하해요!` — 첫 환생 1회 (main.js `onPrestige`)
  - `할인 쿠폰 사용법` — `sawCouponTip` (ui.js)

  → 시드 세이브에 `sawPrestigeIntro:1` 을 넣어 다시 돌리자 **시트·데이터삭제 스위트가 전부 통과**했고,
    명예의 전당·환생 흐름도 API로 직접 실행해 **회차 5→6·돈 리셋·명성 영구 획득**을 확인했다.

**원인 ③ 매크로 방지가 로봇 클릭을 정확히 차단 — 정상 동작**
스타 셰프(미슐랭) 스위트는 `#michTap` 을 **같은 좌표·15ms 등간격**으로 연타한다.
이는 오토클릭 패턴이라 매크로 가드가 막아 별이 오르지 않는다(`res.blocked`).
→ **좌표·간격을 흔들어(사람처럼) 탭하자 별이 정상 상승**하고, 조리수 누적·5성 영구배율까지 동작했다.
   즉 실패가 아니라 안티매크로가 제대로 일하는 증거다.

**직접 조작으로 정상 확인한 기능(타임아웃에 가려졌던 것들)**

| 기능 | 확인 |
|---|---|
| 시트 펼침/접힘 | 핸들 탭 토글, 드래그 위/아래, 251→473px, 항목 0→3개, 접힌 채 조리, 새로고침 유지 |
| 스타 셰프 | 사람처럼 탭 시 별 상승(★☆☆☆☆), 조리수 누적, 결과·최고기록, 5성 영구배율 |
| 명예의 전당 | 순위표 6줄, 명성 내림차순, 동점 시 빠른 회차 우선, 예상 순위 |
| 환생 | 회차 +1, 돈 리셋, 명성 영구, 새로고침 유지 |
| 데이터 삭제·내보내기/불러오기 | 2중 확인 삭제, base64 코드 왕복 복원 |

**권고**: 회귀 테스트로서 값을 되찾으려면 ① SVG→`<img>`(PNG) 및 `★`→이미지 셀렉터 갱신,
② 조작 전 1회성 안내 모달(출석·환생·쿠폰) 닫기 단계 추가, ③ 매크로 검증 대상이 아닌
탭 조작은 좌표·간격을 흔들어 사람처럼 입력하도록 손보면 된다.

### 5.3 참고 — 설계상 정상(오해 주의)

- 주방·환생·기록 탭은 **진행도에 따라 나중에 열린다**(첫 화면엔 3개만).
- `State.save()` 는 저장할 때 `lastSeen` 을 현재로 갱신한다.
  오프라인 보상을 테스트하려면 `lastSeen` 을 되돌린 뒤 `State.save` 를 스텁해야
  `pagehide` 저장이 값을 덮어쓰지 않는다.
- `Game.setClock(fn)` 은 **시각을 돌려주는 함수**(Date 반환)를 받는다. 타임스탬프 숫자를 넘기면 안 된다.

## 6. 결론

- 자동 로직·매크로·진행도 테스트 **전부 통과**.
- 실사용 시나리오(온보딩~데이터 삭제) 전 기능 **정상 동작**을 실제 조작·육안으로 확인.
- 브라우저 테스트 실패 20건을 **전수 추적**한 결과, 기능 결함은 **"원" 중복 문구 1건**뿐이며 수정했다.
  나머지는 전부 ①이미지 셀렉터(그림 재개편 예정이라 무시) ②1회성 안내 모달 미해제 ③매크로 가드의 정상 차단이었고,
  그 뒤에 가려졌던 기능(시트·스타셰프·명예의전당·환생·삭제·백업)은 직접 조작해 정상임을 확인했다.
- 아이콘/그림은 툴로 재개편 예정이므로 그림 관련 실패는 손대지 않았다. 순수 기능만 보면 **결함 없음(수정 1건 반영 후)**.
- 회귀 테스트 값 회복을 원하면 브라우저 스위트를 PNG·1회성 모달·사람형 입력에 맞춰 갱신하면 된다(별도 작업 권고).
